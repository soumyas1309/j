3. DEVIATIONS FROM THE "EXACTLY FOUR FILES" AND "DOUBLE-CLICK" RULES
--------------------------------------------------------------------
Prac 10 has FIVE files: index.html, style.css, script.js, Writeup.txt and students.json.
  Reason: fetch("students.json") and $.getJSON("students.json") read that file, so the practical cannot work
  without it. All other practicals have exactly four files.

Prac 10 cannot be run by double-clicking index.html. Tested in Chromium: from file:// both fetch() and
$.getJSON() fail ("Failed to fetch"). Chrome blocks reading local files this way. Your original code has the same
limit. To run it:
  - VS Code: right-click index.html -> "Open with Live Server", OR
  - Terminal in the "Prac 10 - Load JSON using fetch and jQuery" folder: python -m http.server 8000, then open http://localhost:8000
This is also written in Prac 10 - Load JSON using fetch and jQuery/Writeup.txt.

INTERNET is needed for:
  - Prac 10 and Prac 12: jQuery is loaded from https://code.jquery.com (as in your original code).
  - Prac 12: the "Load Sample Task" button calls https://jsonplaceholder.typicode.com.
If the exam lab has no internet, jQuery will not load and these two will not work. Tell me and I can bundle a
local jquery.min.js file (this adds a file).
